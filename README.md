# claude-mods

Mods for [Claude Code](https://claude.com/claude-code): plugins of function
hooks that change what Claude Code shows and does. They need Claude Code's
early-access plugin hook modules.

| Mod | What it does |
|---|---|
| [stage-toons](stage-toons/README.md) | A stepped progress bar of your development workflow above the prompt, with pixel-art cartoons of Clawd while Claude works |

What's planned next is in [docs/roadmap.md](docs/roadmap.md).
